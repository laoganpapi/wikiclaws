# This is FALSE.  All 6 failures (n<=5) listed; every one has TRUE abundance > 1/2.
#
# masks are bit-encoded subsets of [n]; element i <=> bit i.

# --- the minimal / sharpest counterexample (defeats the whole lever) ---
# F = {emptyset, {4}, {0,1,2,3,4}}   masks [0,16,31]   n=5

#   TRUE abundance = max freq /|F| = 2/3 = 0.6667 > 1/2       <-- Frankl HOLDS, but not via this
