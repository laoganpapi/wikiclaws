# Abstract Algebra, From Zero to Galois

A six-part, beginner-to-advanced course in abstract algebra. Every part is built the same way: plain-English explanations of each term, worked examples, basic exercises with full solutions, advanced exercises with full solutions, and real-world relevance.

There are two ways to use this:

- **Play:** ask Claude to run the interactive, gamified session ("start Algebra Quest"). Minimal reading, lots of doing.
- **Read:** work through the documents below in order. Each one assumes the ones before it.

## The learning path

| # | Document | What you will be able to do |
|---|----------|------------------------------|
| 0 | [Foundations](00_foundations.md) | Speak the language: sets, functions, equivalence relations, modular arithmetic, and the proof moves used everywhere else. |
| 1 | [Group Theory I](01_groups_basics.md) | Recognize a group, work with subgroups and cyclic groups, compute in permutation and dihedral groups, apply Lagrange's theorem. |
| 2 | [Group Theory II](02_groups_advanced.md) | Build quotient groups, use homomorphisms and the isomorphism theorems, run group actions, apply Sylow's theorems. |
| 3 | [Ring Theory](03_rings.md) | Work in rings, spot integral domains and fields, build quotient rings, and factor polynomials. |
| 4 | [Fields & Galois Theory](04_fields_galois.md) | Measure field extensions, construct finite fields, settle ancient compass problems, and see why the quintic is unsolvable. |
| 5 | [Real-World Applications](05_applications.md) | Do RSA and Diffie-Hellman by hand, correct errors with Hamming codes, count with Burnside, and find groups in chemistry, physics, music, and the Rubik's cube. |

## The big picture

Abstract algebra studies *structure*: sets equipped with operations that follow a few rules.

- A **group** captures symmetry and reversible actions (one operation).
- A **ring** adds a second operation, modeling number systems and polynomials.
- A **field** is a ring where you can also divide, the natural home for solving equations.

Master those three and you can read modern cryptography, error-correcting codes, particle physics, and crystallography.
