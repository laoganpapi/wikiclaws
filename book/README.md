# A New Theory of Personality

A book, with Steven Pham. First-pass manuscript.

The theory holds that personality is a set of preferences, stated or revealed, that govern how a
person makes decisions and responds to stimuli, measured at a time and in service of pursuing an
external cause. It is built from separable systems, presented to a uniform template, with the set
of systems left open.

## Manuscript

- `00_architecture.md` — working spine: decisions, the system template, the system register, open
  questions. Not part of the book; read it first.
- `01_introduction.md` — Chapter 1. What the theory measures and why.
- `02_social_energy.md` — Chapter 2. The social energy economy.
- `03_internal_external.md` — Chapter 3. Internal and external observation.
- `04_formal_thinking.md` — Chapter 4. The preference for formal thinking.
